# Шашки — русские шашки онлайн

Сервер (Deno) + сайт + Windows-клиент в одном репозитории.

## Что изменилось

- **Дамка**: ходит и бьёт по всей диагонали в любую сторону; взятие назад работает и с последней линии.
  Ход проверяется на сервере (клиент не может прислать нелегальный ход).
- **Выход из партии**: если соперник не выходит на связь 30 секунд, партия завершается его поражением
  (проверка встроена в long-poll, дополнительных запросов нет).
- **Сдался** — победа сопернику, запись в рейтинге.
- Рейтинг и партии хранятся в Deno KV (при недоступности KV — в памяти процесса).

## Запуск локально

```bash
deno task dev        # http://127.0.0.1:8000
```

## Деплой

Приложение Deno Deploy собирается из этого репозитория (`server.ts`).
Сайт: `/`, браузерная игра: `/play`, клиент: `/download/win`, APK: `/download/apk`.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | статус |
| POST | `/api/queue` | поиск соперника `{name}` |
| POST | `/api/room` | создать комнату `{name}` |
| POST | `/api/room/join` | войти по коду `{code, name}` |
| GET | `/api/game?code=&since=&wait=1` | состояние партии, long-poll |
| POST | `/api/game/move` | ход `{code, seq, from, path, captured}` |
| POST | `/api/game/resign` | сдаться `{code}` |
| GET | `/api/games` | список партий |
| GET | `/api/leaderboard?clientId=` | рейтинг |

Клиент идентифицируется заголовком `X-Client-Id`.
